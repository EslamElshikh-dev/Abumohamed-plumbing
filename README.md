# أبو محمد سباك وكهربائي

موقع عربي ثابت متعدد الصفحات لخدمات السباكة والكهرباء والإنارة داخل مدينة الرياض.

## البناء

يتطلب Python 3 القياسي فقط:

```sh
python3 build.py
```

المخرجات في `dist/` جاهزة للنشر على Vercel، و`vercel.json` يحدد مجلد الإخراج. لتحديث الرابط الأساسي للسكيما والـ canonical وملف Sitemap:

```sh
SITE_URL=https://your-production-domain.example python3 build.py
```

عدّل بيانات النشاط والخدمات في أعلى `build.py` ثم أعد البناء. بيانات الاتصال والعنوان والسكيما تُولّد من القيم نفسها في جميع الصفحات.

منطقة إدارة النشاط: حي المصيف، الرياض. الخدمة تُنفّذ في مواقع العملاء داخل الرياض، ولا يستقبل مقر الإدارة العملاء. بيانات الموقع العامة لا تنشر عنوان السكن التفصيلي أو رابط موقعه؛ يبقى ذلك ضمن تحقق الملف التجاري.

السكيما تشمل السباكة والكهرباء، منطقة الخدمة، بيانات الاتصال، وعلاقات الخدمات بمقدمها. لا تتضمن مراجعات أو ساعات عمل أو أسعارًا غير مؤكدة. عند تحديث محتوى الصفحات، حدّث `LAST_UPDATED` بالتاريخ الفعلي حتى يطابق `dateModified` و`lastmod` في Sitemap. عناوين ملفات CSS وJavaScript تتضمن بصمة محتواها لتحديث الكاش عند التعديل.

إثبات ملكية الموقع في Google Search Console والتحقق من Google Business Profile عمليتان مستقلتان؛ نشر بيانات الموقع لا يُكمل التحقق التجاري وحده.
